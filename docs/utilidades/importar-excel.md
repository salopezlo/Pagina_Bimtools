# ImportarExcel

## Qué hace

Importa la representación visual de una tabla de Excel a una vista de Revit (Legend o Drafting). No importa datos a parámetros de elementos.

Tiene tres modos:

1. **Tabla nativa:** respeta los colores del Excel original.
2. **Estilo BIMTools:** aplica la paleta corporativa azul.
3. **Imagen (PNG):** alta fidelidad, como imagen rasterizada.

Puede leer desde un archivo `.xlsx` o desde una instancia de Excel abierta.
