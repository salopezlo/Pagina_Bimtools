# 11. Presupuesto

## Qué hace

Arma un presupuesto a partir de las cantidades extraídas de las tablas `CANT-`. Las cantidades son automáticas; los precios unitarios se ingresan manualmente.

El resultado es un archivo Excel (.xlsx) con la paleta corporativa, las partidas agrupadas y el AIU: Administración 10 %, Imprevistos 3 % y Utilidad 7 %. Son valores por defecto y se pueden editar.

## Cómo se usa

En la ventana del plugin hay una tabla de partidas. Cada fila trae su cantidad, extraída de las tablas `CANT-`, y el usuario ingresa el valor unitario.

## Requisitos

Tablas de cantidades `CANT-` generadas (ver la página de tablas de cantidades).

## Limitaciones

- No hay una base de datos de precios ni importación de precios desde Excel: solo las cantidades son automáticas.
- El resultado es solo el archivo Excel; no se genera una vista dentro de Revit.
